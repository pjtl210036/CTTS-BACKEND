# 实验总结

本实验完成了"校园实训任务管理系统（CTTS）"后端项目的搭建与验证。首先使用 Spring Initializr 创建 Maven 项目骨架，并在 pom.xml 中引入 Spring Web、MyBatis-Plus、MySQL 驱动及 Lombok 等起步依赖；随后编写 application.yml，配置 8080 服务端口与 MySQL 数据源连接信息；最后编写启动类和一个简单的 HelloController 测试接口。运行项目后，控制台输出 "Started DemoApplication"，Tomcat 在 8080 端口正常启动，访问 /hello 接口成功返回 JSON 数据，说明 Spring 容器、Web 环境及 MyBatis-Plus 均已正常加载，数据源配置无误。通过本次实验，我掌握了 Spring Boot 项目的创建流程、依赖管理与数据源配置方法，为后续业务功能开发奠定了坚实基础。

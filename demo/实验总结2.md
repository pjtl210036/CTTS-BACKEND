# 实验总结（Controller 层接口开发）

本实验完成了"校园实训任务管理系统"Controller 层的开发与调试。首先创建实训项目实体类与 TrainingProjectController，实现查询实训项目列表接口，用内存模拟数据返回 JSON；随后实现按 id 查询单个项目详情接口，通过 @PathVariable 接收路径变量；再实现分页查询接口，通过 @RequestParam 接收页码与每页条数，返回总条数、总页数及当前页记录。最后使用 Apifox 对各接口逐一调试，验证了路径参数、查询参数的接收及 JSON 数据的正确返回。通过本次实验，我掌握了 @RestController、@GetMapping、@PathVariable、@RequestParam 等注解的使用方法，理解了 RESTful 接口的设计与分页逻辑的实现，为后续结合 MyBatis-Plus 与数据库进行业务开发奠定了基础。
